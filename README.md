# 横店楼盘地图前端

React 19、Vite、Ant Design 6、Less、classnames。当前处于 `release/v1.1` 开发中。项目样式统一写在 `.less` 文件中，组合类名使用 `classnames`。

## 本地运行

先启动后端，再运行：

```bash
nvm use 24
npm install
npm run dev
```

浏览 Vite 输出的本机地址；`/` 是展示端，`/admin` 是管理端。`npm run build` 构建静态网页。

横店整体轮廓使用已确认的 72 点手绘边界，由后端随产品打包提供；展示端与管理端共用该数据，不依赖高德 AOI 权限。

## 高德地图常量

仅修改 **`src/config/map-key.local.ts`** 中的 `AMAP_JS_API_KEY`，填写 **Web 端（JS API）** Key。这个值会进入浏览器构建文件，属于可见 Key；不要把 **安全密钥** 或 **Web 服务 Key** 填在前端。

本地文件被 `.gitignore` 忽略。克隆后可从 `src/config/map-key.local.example.ts` 复制模板。安全密钥与 Web 服务 Key 在后端的本地配置文件中填写。

管理后台分为片区与小区、出售／租赁房屋、周边设施、字典列表 4 个菜单。片区与小区页面提供地图、层级树、详情弹窗、单次保存的编辑表单和快速操作表格。废弃小区站可恢复归属或永久删除。设施类型的名称与颜色在字典中统一维护，地图标记显示类型名称首字。地点搜索与配套路线由后端使用 Web 服务 Key 访问高德。数据备份及 Windows 安装包仍在开发中。

房屋信息在出售／租赁房屋菜单维护。选择“出售且租赁”时填写两个价格，一次提交会生成同一房间的两条挂牌。主图必填，户型图可选，详情图最多 6 张；编辑房源时未选择新图则保留现有图片。页面顶部切换售房与租赁，可按小区、片区、楼层、状态、好价和急售筛选。
